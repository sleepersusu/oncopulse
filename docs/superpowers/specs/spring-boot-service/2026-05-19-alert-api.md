# Spring Boot Service — Alert API

## 職責

提供前端查詢、確認（acknowledge）、解決（resolve）Alert 的端點。

## Endpoints

### `GET /api/v1/alerts`

取得 Alert 清單，預設顯示 OPEN 狀態。

**Query Parameters**

| 參數 | 類型 | 說明 |
|---|---|---|
| `status` | string | `OPEN`（預設）/ `ACKNOWLEDGED` / `RESOLVED` / `ALL` |
| `riskLevel` | string | `HIGH` / `MEDIUM` |
| `from` | ISO date | 建立時間起始 |
| `to` | ISO date | 建立時間結束 |
| `page` | int | 頁碼，預設 0 |
| `size` | int | 每頁筆數，預設 20 |
| `sort` | string | 預設 `createdAt,desc` |

**Response 200**

```json
{
  "content": [
    {
      "id": "uuid",
      "patientId": "uuid",
      "patientExternalId": "sha256_hash",
      "riskLevel": "HIGH",
      "triggerReason": "連續 9 天情緒負面（分數均值 0.82）...",
      "status": "OPEN",
      "createdAt": "2026-05-19T10:05:00Z",
      "acknowledgedBy": null,
      "acknowledgedAt": null,
      "resolvedAt": null,
      "notes": null
    }
  ],
  "totalElements": 7,
  "page": 0,
  "size": 20
}
```

---

### `GET /api/v1/alerts/{id}`

取得單一 Alert 詳情，包含該病患最近 7 天情緒摘要。

**Response 200**

```json
{
  "id": "uuid",
  "patientId": "uuid",
  "patientExternalId": "sha256_hash",
  "riskLevel": "HIGH",
  "triggerReason": "連續 9 天情緒負面...",
  "status": "OPEN",
  "createdAt": "2026-05-19T10:05:00Z",
  "patientSummary": {
    "source": "reddit",
    "totalRecords": 42,
    "lastSeenAt": "2026-05-19T09:00:00Z",
    "rollingAvg7d": 0.82,
    "consecutiveNegativeDays": 9,
    "scoreDropPct": 45.2
  }
}
```

---

### `PUT /api/v1/alerts/{id}/acknowledge`

醫護確認已看到 Alert。

**Request Body**

```json
{
  "acknowledgedBy": "Dr. Chen"
}
```

**Response 200**

```json
{
  "id": "uuid",
  "status": "ACKNOWLEDGED",
  "acknowledgedBy": "Dr. Chen",
  "acknowledgedAt": "2026-05-19T10:30:00Z"
}
```

**Response 409** 若 Alert 已是 `ACKNOWLEDGED` 或 `RESOLVED`

```json
{ "error": "Alert already acknowledged" }
```

---

### `PUT /api/v1/alerts/{id}/resolve`

醫護確認已採取行動。

**Request Body**

```json
{
  "notes": "安排心理諮詢，病患已同意下週回診。"
}
```

**Response 200**

```json
{
  "id": "uuid",
  "status": "RESOLVED",
  "resolvedAt": "2026-05-19T11:00:00Z",
  "notes": "安排心理諮詢，病患已同意下週回診。"
}
```

**Response 400** 若 Alert 尚未 `ACKNOWLEDGED` 就嘗試 resolve

```json
{ "error": "Alert must be acknowledged before resolving" }
```

## 狀態機規則

```
OPEN → ACKNOWLEDGED → RESOLVED   ✅ 正常流程
OPEN → RESOLVED                  ❌ 不允許（必須先 acknowledge）
ACKNOWLEDGED → OPEN              ❌ 不允許（不可倒退）
RESOLVED → any                   ❌ 不允許（終態）
```
